# Git Practice
Article: “Coding is dead”? Teaching computer programming in the age of 
AI

Link:(https://www.unesco.org/en/articles/coding-dead-teaching-computer-programming-age-ai)

Reflection: This article is very interesting as it explores the importance 
of still learning how to program even in a time where AI is used for 
everything. The skill of learning how to code helps in building even more 
advanced systems but even AI makes mistakes. The article raises a concern 
that if we stopped learning and teaching people how to code then there 
will be less and less people who understand the programs that they are 
using AI to make. This causes issues when it comes to debugging but also 
just understanding the program that you are meant to work on. The article 
then goes on to say that AI will not replace programmers but will help 
them advance instead which is a similar conversation to the one had during 
our class.
